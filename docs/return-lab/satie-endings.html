Satie: the ending darkens

How does Satie change the tune’s final eight bars?

Thirty-one bars return unchanged: the same piano melody, bass notes and chords. Then the last eight bars turn another way. F♮ replaces F♯, and the piece ends in D minor after its first D-major close.

    How the return sounds

    The score, the players, their instruments and the recording all contribute to the differences you hear.

    The 39 matching bars take 93.2 seconds on return and 88.2 seconds the first time — 6% longer.

    How to read the charts

    Each bar is timed from its aligned start to the next bar. The final bar runs to the end of the recording, including the dying sound.

    The volume chart averages the recording’s normalised amplitude samples, taken twice a second, within each bar. It shows changes within this recording.

    Totals include matching bars only. Columns with a hatched gap are left out.

    How the score is timed

    Public-domain LilyPond/MIDI → voice-aware performed event table; tuning estimated with librosa; Sync Toolbox 1.4.2 memory-restricted multiscale DTW at 50 frames/s, chroma + DLNCO. First/last attacks anchored by score-pitch energy rises in documented inspection windows; section anchors refined by DTW and checked against existing passage labels. Note-offs are warped notation, not measured key releases; final piano holds extend to an estimated decay threshold. No aural review. See tools/align/REPORT.md.
