Satie: one melody, two endings

What changes when the melody reaches its second ending?

Satie repeats the same 31 bars, then changes the last eight. Both endings take the same number of bars, but the final D-major chord becomes D minor. The numbers follow Mutopia’s compact repeat notation: the second ending is 40–47, not 71–78. Timing is aligned automatically, not checked by ear.
