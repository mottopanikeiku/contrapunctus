The Return Lab

The tune is back. Is it doing the same job?

Music keeps its listeners oriented by bringing things back. Here you can hear a passage beside its return in the same recording. On one side, what the score changes; on the other, what changes in the performance.

Each comparison is drawn from the score aligned to a free recording. The alignment is automatic and provisional until someone checks it by ear. Differences in timing and level are measured, not interpreted.
