The comparison

Liszt opens with accented chords, pauses and quick flourishes. Rachmaninoff plays the piano original; Stokowski’s Philadelphia players use Karl Müller-⁠Berghaus’s orchestration. Goehr adds a London performance from Kingsway Hall. In all three recordings this opening begins the first disc side.

How the recordings are matched

The matching follows sequences of pitches, using a method called dynamic time warping. Every recording is mapped to the reference, so switching between two versions goes through that shared clock. Where several reference times match one point, the middle time is used.

  • Leopold Stokowski, Philadelphia Orchestra, 1936: match score 0.929. Matched passages available.
  • Walter Goehr, National Symphony Orchestra of London, 1945: match score 0.788. Check the matched passages by ear before using these timings.

Switching stays within the matched span, and trimmed recordings keep their original clock times. Match scores describe similarity in the sound.
