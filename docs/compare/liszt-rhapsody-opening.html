The comparison

Rachmaninoff’s 1919 Edison side is the piano original; the 1936 Stokowski source credits Karl Müller-Berghaus’s orchestration, while Goehr’s 1945 source leaves the arranger unidentified. Only the shared opening is compared, using each recording’s first side without concatenation. Analysis shifts the orchestral pitch-class features by one semitone, not the playback audio; Goehr’s alignment has median confidence 0.788 and should be used with caution, not for precise tempo claims.

Alignment evidence & limitations

Chroma features describe pitch-class content. Dynamic time warping matches their sequence, then interpolates between sampled pairs of recording times. When switching from a non-reference recording, its map is inverted first, then the chosen performer’s map is applied. Repeated timestamps use the midpoint of the matching reference span.

  • Stokowski, 1936 · side 1: median chroma confidence 0.929. Automatic alignment remains provisional.
  • Goehr, 1945 · side 1: median chroma confidence 0.788. Use with caution: inspect the correspondence before relying on these timings.

Trims retain their original recording offsets. No timing is extrapolated outside a map. Confidence measures feature similarity, not historical or musical certainty.
