The comparison

Paderewski’s 1917 transfer, Pachmann’s 1925 HMV side and Rummel’s 1943 recording are compared with Olga Gurevich’s modern Musopen performance. Pachmann’s original file contains Étude Op. 25 No. 3 first, so only the waltz beginning around 1:57 is aligned. Paderewski’s automatic map is usable only with caution, while Rummel is limited to the shared opening because the later full-file path becomes unreliable. These restrictions preserve the original audio rather than inventing a continuous correspondence across every second.

Alignment evidence & limitations

Chroma features describe pitch-class content. Dynamic time warping matches their sequence, then interpolates between sampled pairs of recording times. When switching from a non-reference recording, its map is inverted first, then the chosen performer’s map is applied. Repeated timestamps use the midpoint of the matching reference span.

  • Paderewski, 1917: median chroma confidence 0.839. Use with caution: inspect the correspondence before relying on these timings.
  • Vladimir de Pachmann, 1925: median chroma confidence 0.929. Automatic alignment remains provisional.
  • Walter Morse Rummel, 1943: median chroma confidence 0.813. Use with caution: inspect the correspondence before relying on these timings.

Trims retain their original recording offsets. No timing is extrapolated outside a map. Confidence measures feature similarity, not historical or musical certainty.
